Built against a tight asset budget: one minimal asset set had to dress several distinct biomes, so the shaders needed enough range to make each biome read differently from the same meshes.

- Character and asset art tech: rigging and skinning in Maya, shader authoring, and particle-system VFX.
- Rendering and memory optimization for large, prop-dense open levels — GPU instancing and SRP Batching case studies and implementation, plus impostors for distant geometry.
- Defined the art workflow and asset pipeline the team built against.
- In-engine cloth and rigid-body physics setup.
